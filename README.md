# Retail Sales Data Analytics Dashboard

## Project Overview

This project is a Retail Sales Data Analytics Dashboard developed using Microsoft Power BI.

The project analyzes the Superstore Sales Dataset to understand sales trends, profitability, product performance, regional performance, and customer segments.

## Objectives

- Analyze retail sales trends
- Identify top-selling products
- Analyze category performance
- Analyze regional performance
- Analyze customer segments
- Calculate important KPIs
- Provide business recommendations

## Dataset

**Dataset:** Superstore Sales Dataset

**Source:** Kaggle

## Tools Used

- Microsoft Power BI
- Power Query
- Excel
- DAX

## Key Performance Indicators

- Total Sales
- Total Profit
- Total Orders
- Total Quantity
- Profit Margin

## Dashboard Visualizations

- Monthly Sales Trend
- Sales by Category
- Profit by Category
- Sales by Region
- Sales by Segment
- Top 10 Products by Sales

## Interactive Filters

- Category
- Region
- Year

## Key Insights

1. Technology has the highest sales.
2. Technology has the highest profit.
3. West region has the highest sales.
4. Consumer segment has the highest sales.
5. Canon imageCLASS 2200 Advanced Copier is the top-selling product.
6. Monthly sales fluctuate but show an overall increasing trend.

## Recommendations

1. Focus on high-performing Technology products.
2. Strengthen sales strategies in the West region.
3. Target the Consumer segment with suitable marketing campaigns.
4. Maintain availability of top-selling products.
5. Monitor monthly sales trends for better inventory planning.

## Conclusion

The Retail Sales Data Analytics Dashboard provides an interactive view of sales and profitability performance. It helps identify important business trends and supports data-driven decision making.
